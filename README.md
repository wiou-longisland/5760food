# 知食 · 食谱社区（桌面网页版）

当前提供两个页面：社区总览与食谱详情。React + TypeScript + Vite，沿用「知食」白底、深绿色 #315C49 与圆角卡片。没有独立注册登录或手机端设计。

## 运行与验证

Node.js 20.19+ 或 22.12+；当前验证版本 24.22.1。

```bash
npm ci
npm run dev
npm run build
```

另开终端保持开发服务器在 5173 端口运行，再执行 `npm test`。测试使用系统 Chromium（`/usr/bin/chromium`，可通过 CHROMIUM_PATH 覆盖）。

## 本版功能

- 7 个大分类：新增抗炎食谱、经典佳肴。
- 5 组小标签：饮食需求、食材/菜品、烹饪与时间、场景、口味。同组 OR，跨组 AND；没有样例的标签明确显示空结果。
- 上周最受欢迎：固定 2026-10-26 至 2026-11-01 虚拟收藏快照，按新增收藏量选榜首，与本地收藏操作分开。
- 4 份可切换虚拟饮食档案；综合推荐：显式冲突后置 → 偏好匹配数降序 → 上周收藏数降序。其他排序按选择排序，冲突仍有提示，可选择隐藏。
- 详情页多图、文字、分组标签、配料份数换算、步骤、每份营养与冲突/待确认信息。
- 点赞、收藏、档案选择保存在 localStorage，仅当前浏览器有效。
- Hash 深链接，例如 `/#/recipe/salmon`，刷新仍能访问详情。
- 图片通过 SVG viewBox 取出六宫格对应区域，再等比例裁切；不拉伸照片。原始素材未改动。

本次按需求聚焦两个页面，早期版本的发布表单不在此版导航中。未来发帖等对接说明见 docs/integration.md。

## API 与数据边界

所有食谱、作者、营养、标签、档案、统计都是演示数据。未调用 USDA、DeepSeek、Cloudinary，不需要密钥，也不会消耗付费额度。“抗炎食谱”为编辑主题，不是治疗承诺；营养与限制标签未经真实数据校验。匹配只检查已知食材，不保证过敏安全。

示例图片由 AI 生成，不是实际菜品记录；图片本身不提供配料或营养证据。图标来自 lucide-react（ISC）。

## 部署

普通静态托管：上传 `dist/` 的内容，网站根目录访问。

GitHub Pages 项目站点：`DEPLOY_BASE=/5760food/ npm run build`，发布 dist 到 gh-pages。需要在 GitHub Settings → Pages 选择 Deploy from a branch → gh-pages → /(root)。仅推送分支不等于 Pages 已发布；以实际网页请求成功为准。

同学现有 Cloudflare 服务不受本模块影响。真实档案和登录尚未接入；代码合并步骤与接口契约见 docs/integration.md。
